# sales-dashboard-analysis
Interactive sales performance dashboard built using Power BI

Project Overview.
This project presents an interactive sales dashboard built using Power BI.  
The dashboard analyzes sales performance across regions, product categories, and time to provide insights into business trends and revenue drivers.

The objective of the project is to demonstrate the use of data visualization and business intelligence tools to monitor sales performance and support data-driven decision making.

 Dataset
The project uses the Superstore Sales dataset which contains transactional sales data including:

- Order Date
- Product Name
- Category
- Region
- Sales

The dataset represents retail sales transactions across multiple regions and product categories.

 Tools Used
- Power BI
- Data Visualization
- Basic Data Modeling

Dashboard Features
The dashboard contains several analytical components:

  1. KPI Metric
   Displays the **Total Sales** value to provide a quick overview of overall revenue.

  2. Sales Trend Analysis
    A line chart visualizing **sales performance over time**, helping identify growth patterns.

  3. Regional Performance
   A bar chart comparing **sales across regions** to identify the highest performing areas.

  4. Category Analysis
   A chart displaying **sales by product category** to understand which categories generate the most revenue.

  5. Product Performance
   A bar chart showing **top selling products** based on total sales.

  6. Interactive Filtering
    Users can interact with the dashboard by selecting regions or dates to dynamically update the analysis.

Key Insights
- The **West region** generates the highest sales compared to other regions.
- **Technology products** contribute the largest share of revenue.
- Sales show a **consistent upward trend over the years**, indicating business growth.
- A small number of products account for a significant portion of total sales.


 Project Outcome
The dashboard demonstrates how Power BI can be used to transform raw sales data into meaningful insights through interactive visualizations.
